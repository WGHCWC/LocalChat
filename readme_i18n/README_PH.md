# LocalChat

LocalChat ay isang real-time chat at file transfer app para sa lokal na network, na binago mula sa [LocalSend](https://github.com/localsend/localsend). Pinapanatili nito ang local-network discovery, HTTPS transfer, at cross-platform foundation ng LocalSend, habang dinadagdagan ng chatroom, message synchronization, at file download experience.

## Pangunahing tampok

- Awtomatikong nakakatuklas ng mga online device sa parehong local network nang walang external server.
- Sumusuporta sa real-time na pagpapadala at pagtanggap ng text message sa LAN chatroom.
- Sumusuporta sa message synchronization sa maraming device; maaaring i-sync ng online devices ang message history.
- Sumusuporta sa pagpapadala ng files, images, media, at text.
- Sumusuporta sa pag-download ng files mula sa chat messages na hindi pa naka-save locally.
- Sumusuporta sa image preview, pagbukas ng file, at pagpapakita ng local file sa file manager.
- Nakakakilala ng links sa chat messages at binubuksan ang mga ito sa system browser.
- Sumusuporta sa builds para sa Android, macOS, Windows, Linux, at iOS.
