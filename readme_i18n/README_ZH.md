# LocalChat

LocalChat 是一款基于局域网的实时聊天和文件传输应用，基于 [LocalSend](https://github.com/localsend/localsend) 修改而来。它保留了 LocalSend 的本地网络发现、HTTPS 传输和跨平台能力，并围绕聊天室、消息同步和文件下载体验做了扩展。

## 主要功能

- 在同一局域网内自动发现在线设备，不依赖外部服务器。
- 支持局域网聊天室实时收发文字消息。
- 支持多设备消息同步，在线设备可以同步历史消息。
- 支持发送文件、图片、媒体和文本内容。
- 支持在聊天消息中下载未保存到本地的文件。
- 支持图片预览、文件打开和在文件管理器中定位本地文件。
- 支持识别聊天中的超链接，并使用系统浏览器打开。
- 支持 Android、macOS、Windows、Linux 和 iOS 等平台构建。
