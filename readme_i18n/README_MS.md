# LocalChat

LocalChat ialah aplikasi sembang masa nyata dan pemindahan fail untuk rangkaian tempatan, diubah suai daripada [LocalSend](https://github.com/localsend/localsend). Ia mengekalkan penemuan peranti rangkaian tempatan, pemindahan HTTPS dan asas merentas platform LocalSend, sambil menambah pengalaman bilik sembang, penyegerakan mesej dan muat turun fail.

## Ciri utama

- Mengesan peranti dalam talian secara automatik dalam rangkaian tempatan yang sama tanpa pelayan luaran.
- Menyokong penghantaran dan penerimaan mesej teks masa nyata dalam bilik sembang LAN.
- Menyokong penyegerakan mesej antara berbilang peranti; peranti dalam talian boleh menyegerakkan sejarah mesej.
- Menyokong penghantaran fail, imej, media dan teks.
- Menyokong muat turun fail daripada mesej sembang yang belum disimpan secara setempat.
- Menyokong pratonton imej, membuka fail dan memaparkan fail setempat dalam pengurus fail.
- Mengecam pautan dalam mesej sembang dan membukanya dengan pelayar sistem.
- Menyokong binaan untuk Android, macOS, Windows, Linux dan iOS.
