# LocalChat

LocalChat, [LocalSend](https://github.com/localsend/localsend) temel alınarak degistirilmis, yerel ag icin gercek zamanli sohbet ve dosya aktarim uygulamasidir. LocalSend'in yerel ag cihaz kesfi, HTTPS aktarimi ve cok platformlu temelini korur; sohbet odasi, mesaj senkronizasyonu ve dosya indirme deneyimi ekler.

## Temel ozellikler

- Harici sunucuya gerek duymadan ayni yerel agdaki cevrim ici cihazlari otomatik olarak bulur.
- LAN sohbet odasinda metin mesajlarini gercek zamanli gonderip almayi destekler.
- Birden fazla cihaz arasinda mesaj senkronizasyonunu destekler; cevrim ici cihazlar mesaj gecmisini senkronize edebilir.
- Dosya, resim, medya ve metin gonderimini destekler.
- Yerel olarak kaydedilmemis dosyalari sohbet mesajlarindan indirmeyi destekler.
- Resim onizleme, dosya acma ve yerel dosyayi dosya yoneticisinde gosterme destegi sunar.
- Sohbet mesajlarindaki baglantilari tanir ve sistem tarayicisinda acar.
- Android, macOS, Windows, Linux ve iOS icin build almayi destekler.
