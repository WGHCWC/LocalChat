# LocalChat

LocalChat은 [LocalSend](https://github.com/localsend/localsend)를 기반으로 수정한 로컬 네트워크용 실시간 채팅 및 파일 전송 앱입니다. LocalSend의 로컬 네트워크 기기 검색, HTTPS 전송, 크로스 플랫폼 기반을 유지하면서 채팅방, 메시지 동기화, 파일 다운로드 경험을 확장했습니다.

## 주요 기능

- 외부 서버 없이 같은 로컬 네트워크의 온라인 기기를 자동으로 찾습니다.
- LAN 채팅방에서 텍스트 메시지를 실시간으로 주고받을 수 있습니다.
- 여러 기기 간 메시지 동기화를 지원하며, 온라인 기기는 메시지 기록을 동기화할 수 있습니다.
- 파일, 이미지, 미디어, 텍스트 전송을 지원합니다.
- 아직 로컬에 저장되지 않은 파일을 채팅 메시지에서 다운로드할 수 있습니다.
- 이미지 미리보기, 파일 열기, 파일 관리자에서 로컬 파일 표시를 지원합니다.
- 채팅 메시지의 링크를 인식하고 시스템 브라우저로 엽니다.
- Android, macOS, Windows, Linux, iOS 빌드를 지원합니다.
