# LocalChat

LocalChat es una aplicacion de chat en tiempo real y transferencia de archivos para redes locales, modificada a partir de [LocalSend](https://github.com/localsend/localsend). Conserva el descubrimiento de dispositivos en la red local, las transferencias HTTPS y la base multiplataforma de LocalSend, y anade funciones orientadas a salas de chat, sincronizacion de mensajes y descarga de archivos.

## Funciones principales

- Descubre automaticamente dispositivos en linea dentro de la misma red local sin depender de un servidor externo.
- Permite enviar y recibir mensajes de texto en tiempo real en una sala de chat LAN.
- Sincroniza mensajes entre varios dispositivos; los dispositivos en linea pueden recuperar el historial.
- Permite enviar archivos, imagenes, contenido multimedia y texto.
- Permite descargar desde el chat archivos que aun no estan guardados localmente.
- Soporta vista previa de imagenes, apertura de archivos y localizacion de archivos en el gestor del sistema.
- Detecta enlaces en los mensajes y los abre con el navegador del sistema.
- Soporta compilaciones para Android, macOS, Windows, Linux e iOS.
