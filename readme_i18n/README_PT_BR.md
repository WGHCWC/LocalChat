# LocalChat

LocalChat e um aplicativo de chat em tempo real e transferencia de arquivos para rede local, modificado a partir do [LocalSend](https://github.com/localsend/localsend). Ele mantem a descoberta de dispositivos na rede local, as transferencias HTTPS e a base multiplataforma do LocalSend, adicionando recursos de sala de chat, sincronizacao de mensagens e download de arquivos.

## Principais recursos

- Descobre automaticamente dispositivos online na mesma rede local sem depender de servidor externo.
- Suporta envio e recebimento de mensagens de texto em tempo real em uma sala de chat LAN.
- Suporta sincronizacao de mensagens entre varios dispositivos; dispositivos online podem sincronizar o historico.
- Suporta envio de arquivos, imagens, midia e texto.
- Permite baixar, a partir do chat, arquivos que ainda nao foram salvos localmente.
- Suporta pre-visualizacao de imagens, abertura de arquivos e localizacao de arquivos no gerenciador do sistema.
- Reconhece links em mensagens de chat e os abre com o navegador do sistema.
- Suporta builds para Android, macOS, Windows, Linux e iOS.
