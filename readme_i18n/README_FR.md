# LocalChat

LocalChat est une application de chat en temps reel et de transfert de fichiers sur reseau local, modifiee a partir de [LocalSend](https://github.com/localsend/localsend). Elle conserve la decouverte locale des appareils, les transferts HTTPS et la base multiplateforme de LocalSend, puis ajoute des fonctions orientees salon de discussion, synchronisation des messages et telechargement de fichiers.

## Fonctionnalites principales

- Decouvre automatiquement les appareils en ligne sur le meme reseau local, sans serveur externe.
- Prend en charge l'envoi et la reception de messages texte en temps reel dans un salon LAN.
- Synchronise les messages entre plusieurs appareils; les appareils en ligne peuvent recuperer l'historique.
- Permet d'envoyer des fichiers, images, medias et textes.
- Permet de telecharger depuis le chat les fichiers qui ne sont pas encore enregistres localement.
- Prend en charge l'apercu des images, l'ouverture de fichiers et l'affichage d'un fichier local dans le gestionnaire de fichiers.
- Detecte les liens dans les messages et les ouvre avec le navigateur du systeme.
- Prend en charge les builds Android, macOS, Windows, Linux et iOS.
