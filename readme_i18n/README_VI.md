# LocalChat

LocalChat la ung dung chat thoi gian thuc va truyen file trong mang cuc bo, duoc chinh sua tu [LocalSend](https://github.com/localsend/localsend). Ung dung giu lai kha nang phat hien thiet bi trong mang cuc bo, truyen qua HTTPS va nen tang da nen tang cua LocalSend, dong thoi bo sung trai nghiem phong chat, dong bo tin nhan va tai file.

## Tinh nang chinh

- Tu dong tim thiet bi dang online trong cung mang cuc bo ma khong can may chu ben ngoai.
- Ho tro gui va nhan tin nhan van ban thoi gian thuc trong phong chat LAN.
- Ho tro dong bo tin nhan giua nhieu thiet bi; thiet bi online co the dong bo lich su tin nhan.
- Ho tro gui file, hinh anh, media va van ban.
- Ho tro tai file tu tin nhan chat khi file chua duoc luu cuc bo.
- Ho tro xem truoc hinh anh, mo file va hien thi file cuc bo trong trinh quan ly file.
- Nhan dien lien ket trong tin nhan chat va mo bang trinh duyet he thong.
- Ho tro build cho Android, macOS, Windows, Linux va iOS.
