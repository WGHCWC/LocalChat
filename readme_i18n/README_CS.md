# LocalChat

LocalChat je aplikace pro real-time chat a prenos souboru v lokalni siti, upravena na zaklade projektu [LocalSend](https://github.com/localsend/localsend). Zachovava lokalni vyhledavani zarizeni, HTTPS prenosy a multiplatformni zaklad LocalSendu a rozsiruje je o chatovaci mistnosti, synchronizaci zprav a pohodlnejsi stahovani souboru.

## Hlavni funkce

- Automaticky vyhledava online zarizeni ve stejne lokalni siti bez externiho serveru.
- Podporuje real-time odesilani a prijem textovych zprav v LAN chatovaci mistnosti.
- Podporuje synchronizaci zprav mezi vice zarizenimi; online zarizeni mohou synchronizovat historii.
- Podporuje odesilani souboru, obrazku, medii a textu.
- Umoznuje stahnout soubory z chatovych zprav, ktere jeste nejsou ulozene lokalne.
- Podporuje nahled obrazku, otevreni souboru a zobrazeni lokalniho souboru ve spravci souboru.
- Rozpoznava odkazy v chatu a otevira je v systemovem prohlizeci.
- Podporuje sestaveni pro Android, macOS, Windows, Linux a iOS.
