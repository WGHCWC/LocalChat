# LocalChat

LocalChat adalah aplikasi chat real-time dan transfer file untuk jaringan lokal, dimodifikasi dari [LocalSend](https://github.com/localsend/localsend). LocalChat mempertahankan penemuan perangkat lokal, transfer HTTPS, dan fondasi lintas platform dari LocalSend, lalu menambahkan pengalaman ruang chat, sinkronisasi pesan, dan unduhan file.

## Fitur utama

- Menemukan perangkat online secara otomatis di jaringan lokal yang sama tanpa server eksternal.
- Mendukung kirim dan terima pesan teks real-time di ruang chat LAN.
- Mendukung sinkronisasi pesan antar beberapa perangkat; perangkat online dapat menyinkronkan riwayat pesan.
- Mendukung pengiriman file, gambar, media, dan teks.
- Mendukung pengunduhan file dari pesan chat yang belum tersimpan secara lokal.
- Mendukung pratinjau gambar, membuka file, dan menampilkan file lokal di pengelola file.
- Mengenali tautan di pesan chat dan membukanya dengan browser sistem.
- Mendukung build untuk Android, macOS, Windows, Linux, dan iOS.
