# LocalChat

LocalChat — это приложение для чата в реальном времени и передачи файлов в локальной сети, измененное на основе [LocalSend](https://github.com/localsend/localsend). Оно сохраняет локальное обнаружение устройств, HTTPS-передачу и кроссплатформенную основу LocalSend, а также добавляет функции чат-комнат, синхронизации сообщений и загрузки файлов.

## Основные возможности

- Автоматически находит онлайн-устройства в одной локальной сети без внешнего сервера.
- Поддерживает отправку и получение текстовых сообщений в реальном времени в LAN-чате.
- Поддерживает синхронизацию сообщений между несколькими устройствами; онлайн-устройства могут синхронизировать историю.
- Поддерживает отправку файлов, изображений, медиа и текста.
- Позволяет скачивать из чата файлы, которые еще не сохранены локально.
- Поддерживает предпросмотр изображений, открытие файлов и показ локального файла в файловом менеджере.
- Распознает ссылки в сообщениях и открывает их в системном браузере.
- Поддерживает сборки для Android, macOS, Windows, Linux и iOS.
