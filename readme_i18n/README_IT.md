# LocalChat

LocalChat e un'app per chat in tempo reale e trasferimento file su rete locale, modificata a partire da [LocalSend](https://github.com/localsend/localsend). Mantiene la scoperta dei dispositivi in rete locale, i trasferimenti HTTPS e la base multipiattaforma di LocalSend, aggiungendo funzioni per stanze chat, sincronizzazione dei messaggi e download dei file.

## Funzioni principali

- Scopre automaticamente i dispositivi online nella stessa rete locale senza server esterni.
- Supporta invio e ricezione di messaggi di testo in tempo reale in una stanza chat LAN.
- Supporta la sincronizzazione dei messaggi tra piu dispositivi; i dispositivi online possono sincronizzare la cronologia.
- Supporta l'invio di file, immagini, media e testo.
- Permette di scaricare dai messaggi chat i file non ancora salvati localmente.
- Supporta anteprima immagini, apertura file e localizzazione dei file nel file manager.
- Riconosce i link nei messaggi e li apre con il browser di sistema.
- Supporta build per Android, macOS, Windows, Linux e iOS.
